# Uhm test audio

`filler-uh.wav` is derived from [En-us-uh.ogg by Dvortygirl](https://commons.wikimedia.org/wiki/File:En-us-uh.ogg).
It is shared under the [CC BY-SA 3.0 Unported license](https://creativecommons.org/licenses/by-sa/3.0/).
The test fixture converts the recording to 16 kHz mono PCM16 and adds 750 ms of silence at each end.
The original Ogg file has SHA-1 `80c7673f8c9cc5f58e373acde01348b3205e6208`.
